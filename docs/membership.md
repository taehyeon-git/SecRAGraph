# Local member login and report ownership

SecRAGraph's local Compose web UI uses member login. Create accounts with `security-review create-user <username>` on the API host; the command prompts for and confirms a password without echo. Self-registration is disabled by default and can only be enabled explicitly in a development environment. The optional `SECRAGRAPH_API_TOKEN` is an operator credential for trusted automation, not a web-user identity. The Streamlit container does not receive it.

`POST /v1/auth/login` exchanges a username/password for an opaque session token. Streamlit keeps it in server-side session state, sends `Authorization: Session <token>` to the backend, and clears it on logout or 401. The backend stores only the token's SHA-256 digest. Sessions expire after eight hours absolutely or 30 minutes idle; logout and account disable revoke them. Passwords use randomly salted, versioned scrypt verifiers (`N=32768`, `r=8`, `p=3`). Five failed logins lock an account for 15 minutes; `security-review unlock-user <username>` is the local recovery command.

The ASGI gate checks credentials before multipart bodies are read. It rejects duplicate or malformed Authorization headers and fails closed when session persistence is unavailable. Only the login route and explicitly enabled development registration are open under `/v1/`. Health routes remain separate. Reports created by a member store that member's UUID in the same database transaction as the report. JSON, Markdown, and SARIF retrieval all filter by owner and return the same 404 for missing and foreign IDs. Existing reports have a null owner and require an operator Bearer token.

This is a **local portfolio deployment**, bound to host loopback by Compose. There is no public-service rate limiter, MFA, email recovery, tenant administration, or browser cookie flow. Keep the ports local, protect database backups, and do not use the shared operator token in a browser-facing web container. A separate model-provider API key is still required for live OpenAI-backed RAG; member login only controls access to this application.
